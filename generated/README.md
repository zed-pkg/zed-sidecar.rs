# Generated sidecar bindings

> **Do not edit files below this directory by hand.**

The Rust, TypeScript, Dart, and Gleam bindings in this directory are generated
from the repository-owned `.cli-flags.toml` contract by `flags-2-env`. They must
remain semantically aligned across languages.

## Authoritative inputs

- `.cli-flags.toml` — flag names, environment keys, defaults, help text, and
  visibility policy;
- the pinned `flags-2-env` generator/version used by the owning workflow or
  release process.

## Required regeneration behavior

A change to the input contract or generator must regenerate **all** language
subdirectories in one reviewable change. Generated output must be deterministic,
contain its `Generated by flags-2-env from .cli-flags.toml. Do not edit.` header,
and remain free of credentials or machine-specific paths.

Reviewers should reject isolated hand edits to `generated/rust`,
`generated/typescript`, `generated/dart`, or `generated/gleam`. Runtime behavior
belongs in the generator or source contract, not in one generated target.
